# Сервер обновлений N Plugin

Сервер — любой статический HTTP-хостинг (IIS, nginx, веб-сервер сетевого диска и т.п.).
URL задаётся в конфигурации апдейтера (`%LocalAppData%\NPlugin\updater.config.json`, поле `serverUrl`
или в окне апдейтера кнопкой «Сохранить»).

## Состав каталога на сервере

```
<serverUrl>/
  manifest.json                  — описание последнего релиза
  NPlugin-1.0.0-revit2022.zip    — пакет бинарников для Revit 2022
  NPlugin-1.0.0-revit2023.zip
  ...
```

Всё генерируется скриптом `build\pack.ps1`:

```powershell
powershell -File build\pack.ps1 -Version 1.0.1 -ReleaseNotes "Исправления пакетной печати"
```

После выполнения содержимое `dist\server` заливается на сервер (поверх старых файлов).

## Формат manifest.json

```json
{
  "version": "1.0.1",
  "date": "2026-11-06",
  "minUpdaterVersion": "1.0.0",
  "releaseNotes": "Исправления пакетной печати",
  "packages": [
    { "revitVersion": "2022", "fileName": "NPlugin-1.0.1-revit2022.zip", "sha256": "…", "size": 123456 }
  ]
}
```

- `version` — версия плагина, семантическая `x.y.z`. Апдейтер сравнивает с `%LocalAppData%\NPlugin\version.json`.
- `packages` — по одному ZIP на версию Revit. Апдейтер скачивает только пакеты для версий Revit,
  реально установленных на ПК (по папкам `%AppData%\Autodesk\Revit\Addins\<версия>`).

## Как работает обновление

1. Апдейтер (`NPlugin.Updater.exe`, отдельная desktop-программа) читает `manifest.json`.
2. Если версия на сервере новее локальной — скачивает нужные ZIP, проверяет SHA256.
3. Если Revit запущен — обновление откладывается (флаг `update.pending`), применится при следующем запуске.
4. Иначе: бэкап текущих файлов → замена → генерация `.addin`-манифестов → запись `version.json`.
   При любой ошибке — откат на бэкап.
5. Запуск: вручную, кнопкой «Проверить обновления» на ленте Revit, автозапуском при входе
   в Windows (аргумент `/silent` — без окна). Если планировщик задач недоступен без прав
   администратора, установщик прописывает автозапуск в `HKCU\...\Run` — механизм тот же.

## Установка на новый ПК

Скопировать на ПК папки `dist` и `install` и запустить `install\install.bat`.
Переустановка поверх существующей: текущие файлы переименовываются в `*.bak-<дата>`
(переименование работает даже в средах, где прямое удаление файлов заблокировано),
затем распаковываются новые.

## Локальная разработка

Вместо сервера подойдёт локальный HTTP. Вариант без Python — `tools\serve.ps1`:

```powershell
powershell -File tools\serve.ps1 -Root dist\server -Port 8080
# updater.config.json → "serverUrl": "http://localhost:8080"
```

Или классический `python -m http.server 8080` в папке `dist\server`.
